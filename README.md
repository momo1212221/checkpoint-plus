# Checkpoint Plus

Adds safe warm quick-checkpoints for RAC1.

- L1 + R1 + Square: save a quick checkpoint.
- L1 + R1 + Triangle: restore it.
- Optionally creates a checkpoint shortly after each level load.
- Snapshots are limited to the current level load and are not cold save files.

Built for OpenRAC RAC1 PAL/NTSC-U. AI-assisted implementation. GPL-3.0-or-later.
